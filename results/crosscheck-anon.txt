======================================================================
독립 구현 교차검증 — PostgreSQL Anonymizer 1.3.2
======================================================================

[1] 하드닝 전 — anon 기본 배포 상태
----------------------------------------------------------------------
  기준선 (마스킹 동작 확인)        **************
  ★ 마스킹 롤이 search_path 되돌림 800102-1000001
  ★ 스키마 수식 직접 조회         800102-1000001

  → anon 의 동적 마스킹은 **롤의 search_path 를 조작**하는 방식이다
    (anon 문서: "the search_path of the masked role is rigged").
    롤이 자기 search_path 를 되돌리면 그대로 뚫린다 -- 우리 뷰 베이스라인의
    우회 3/3 과 **같은 메커니즘, 같은 결과**다.

[2] anon 문서가 권장하는 하드닝 적용 (REVOKE)
----------------------------------------------------------------------
  search_path 되돌리기                   ERROR:  permission denied for table cust
  스키마 수식                           ERROR:  permission denied for table cust
  정상 조회                              **************
  → 우회는 막혔다. 대가는 원본 스키마 권한 회수이며, 쓰기 경로·배치
    계정·예외 업무가 전부 영향을 받는다(우리가 뷰 방식에 대해 적은 것과 동일).

[3] ★★ 하드닝 후에도 의미 발산이 남는가 — 이것이 이 시험의 핵심
----------------------------------------------------------------------
  count(DISTINCT ssn)                원본=200                마스킹 롤=1
  DISTINCT 행 수                   원본=200                마스킹 롤=1
  ORDER BY ssn LIMIT 5 의 id        원본=28,56,84,112,140   마스킹 롤=1,2,3,4,5
  max(ssn) (값 보존 집계)       원본=800128-1000195     마스킹 롤=**************

  → 에러도 경고도 없다. anon 문서 어디에도 이 클래스에 대한 언급이 없다.

[4] 스키마 진화 — anon 은 SECURITY LABEL(OID 키잉)을 쓴다
----------------------------------------------------------------------
  ALTER TABLE RENAME 후                     **************
  RENAME COLUMN 시도                       PL/pgSQL function anon.trg_mask_update() line 5 at PERFORM
  → RENAME TABLE 은 살아남는다. SECURITY LABEL 이 pg_seclabel 에 **OID 로**
    저장되기 때문이다 -- 우리가 4R 후 OID 키잉으로 바꾼 결정을 독립적으로
    확인해 준다. 우리가 틀렸고 anon 이 처음부터 맞았던 유일한 축이다.
  → 대신 RENAME COLUMN 은 **아예 막힌다**(마스킹 뷰가 의존). 뷰 방식은
    보안을 지키는 대신 정상적인 스키마 진화를 막는다.

[5] 물질화 사본
----------------------------------------------------------------------
  CTAS 사본 조회                         800102-1000001
  → 평문. 우리 2R 이 규명한 물질화 클래스가 그대로 재현된다.
